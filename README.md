# Muhib Khan: AI Engineer Portfolio (React + JavaScript)

Built with React 18 and Vite.

## Run it
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production files in /dist
```

## Edit your content
All text lives in `src/data/portfolio.js`: your details, projects, skills,
education and links. Your CV is `public/Muhib_Khan_Resume.pdf` (replace the file to update it).

## Deploy
Upload the `dist/` folder to Netlify, Vercel or GitHub Pages (built with a relative base path).
